# Quantum Flight Route Optimizer

The Quantum Flight Route Optimizer is a project that explores how quantum computing can be used to solve real-world problems, especially in the field of air transportation. The main idea behind this project is to find suitable flight routes by comparing their costs and identifying more efficient options.

We built this project using Python and Streamlit. Python handles the calculations and optimization logic, while Streamlit provides a simple, interactive dashboard that allows users to view the results easily.

Our project is based on the Quantum Approximate Optimization Algorithm (QAOA), a quantum algorithm designed to solve optimization problems. It uses quantum circuits along with classical computing techniques to search for good solutions to complex problems. Through this project, we aim to understand how such algorithms can be applied to flight route planning.

The dashboard displays different route options and their associated costs, making it easier to compare the results. It also helps users understand how optimization techniques can support better decision-making in transportation.

One of the main goals of this project is to make quantum computing more understandable by demonstrating its practical applications through a working web application. We hope to improve the project in the future by including more airports, travel time, fuel consumption, and comparisons with classical optimization methods.

Overall, the Quantum Flight Route Optimizer is an educational project that combines quantum computing, programming, and transportation. It gave us an opportunity to explore emerging technologies and understand how they might help solve complex optimization problems in the future.
